# 📝 Exami — ระบบสอบออนไลน์ + คอร์สเรียน โอเพนซอร์ส พร้อม AI ฟรี

ระบบสร้างข้อสอบออนไลน์เพื่อสังคม ครูสร้างข้อสอบเองหรือให้ AI ช่วยออกข้อสอบ แชร์ลิงก์ให้ผู้เรียนทำ รู้ผลทันที
ให้ AI ช่วยตรวจข้อเขียน และสร้างคอร์สเรียนแบบง่ายพร้อมติดตามความก้าวหน้าผู้เรียน

- AI ใช้โมเดลโอเพนซอร์สผ่าน **[Ollama](https://ollama.com)** ที่รันบนเซิร์ฟเวอร์ของคุณเอง จึงไม่มีค่า API
- ฐานข้อมูลเป็น **SQLite** ไฟล์เดียว ไม่ต้องติดตั้ง Database แยก
- ติดตั้งด้วย **Dockerfile ไฟล์เดียว** (มี AI ในตัว) บน **Coolify** ได้ใน 3 ขั้นตอน ไม่ต้องตั้งค่าตัวแปรใดๆ

---

## 🚀 ติดตั้ง (Coolify แบบ Dockerfile — 3 ขั้นตอน ไม่ต้องตั้งตัวแปรใดๆ)

ทุกอย่างอยู่ใน **คอนเทนเนอร์เดียว** ได้แก่ เว็บ, SQLite และ AI (Ollama + โมเดล `qwen3:4b` ที่ดาวน์โหลดให้อัตโนมัติ)

1. Coolify → **+ New → Dockerfile** → วางเนื้อหาไฟล์ [`Dockerfile.coolify`](Dockerfile.coolify) (หรือเลือก repo นี้แล้วตั้ง Build Pack = **Dockerfile**)
2. ตั้ง **Ports Exposes** = `3000` · **Domains** = `https://exami.org` · **Persistent Storage** → Volume Mount → Destination Path **`/data`**
3. กด **Deploy** → เปิดเว็บ → **สมัครคนแรก = แอดมิน** → ตั้งค่าทุกอย่างที่ **ผู้ดูแล → ตั้งค่าเว็บไซต์**

📖 คู่มือละเอียดพร้อมวิธีแก้ปัญหาและสำรองข้อมูล → **[INSTALL.md](INSTALL.md)**

| สเปกเซิร์ฟเวอร์ | โมเดลที่เหมาะ |
|---|---|
| RAM 4GB | `qwen2.5:3b` |
| RAM 6GB+ | `qwen3:4b` (**ค่าเริ่มต้น**) |
| RAM 10GB+ | `qwen3:8b` (ภาษาไทยดีขึ้น) |
| RAM 16GB+ / มี GPU | `gemma3:12b`, `qwen3:14b` |

### 🔄 เปลี่ยน / อัปเดตโมเดล AI
ไปที่ **ผู้ดูแล → 🤖 จัดการโมเดล AI** ทำได้ทุกอย่างจากหน้าเว็บ
- ดาวน์โหลดโมเดล (มีแถบความคืบหน้า), 🧪 ทดสอบภาษาไทย/ความเร็ว, กด “ใช้โมเดลนี้” และลบโมเดลเก่า
- ระบบเทียบ RAM ของเซิร์ฟเวอร์ให้อัตโนมัติ
- **แจ้งเตือนเอง** (จุดแดงที่เมนูผู้ดูแล) เมื่อโมเดลมีเวอร์ชันใหม่ หรือมีโมเดลแนะนำใหม่ใน `ai-models.json` บน GitHub
- ใช้ AI server เครื่องอื่นได้ เช่น เครื่อง GPU แยก: ตั้งที่ **ตั้งค่าเว็บไซต์ → AI → ที่อยู่ AI Server**

## ✨ ฟีเจอร์

### ข้อสอบ 10 รูปแบบ
| รูปแบบ | ตรวจ |
|---|---|
| ตัวเลือก (ข้อเดียว), ตัวเลือก (หลายข้อ แบบให้คะแนนบางส่วนได้), ถูก/ผิด | อัตโนมัติ |
| จับคู่ (มีตัวลวงได้), เรียงลำดับ | อัตโนมัติ + คะแนนบางส่วน |
| เติมคำตอบสั้น (ใส่คำตอบที่ยอมรับได้หลายคำ) | อัตโนมัติ |
| เติมคำในช่องว่าง `เมืองหลวงคือ {{กรุงเทพ\|กรุงเทพมหานคร}}` | อัตโนมัติ (คะแนนตามช่อง) |
| เขียนอธิบาย/ตอบยาว (มี Rubric) | AI หรือผู้สอน |
| แนบลิงก์คำตอบ (YouTube/URL พร้อมพรีวิว) | ผู้สอน (AI ช่วยได้เบื้องต้น) |
| แนบไฟล์คำตอบ (กำหนดนามสกุลได้) | ผู้สอน |

ทุกข้อแนบรูปประกอบโจทย์ได้ ใส่คำอธิบายเฉลยได้ และกำหนดคะแนนแยกรายข้อได้

### การสอบ
- แชร์ลิงก์พร้อม **QR Code** ผู้เรียนไม่ต้องสมัครก็ทำได้ (กรอกชื่อ + รหัส) หรือจะบังคับให้ล็อกอินก็ได้
- ตั้งได้ทั้ง จับเวลา (บังคับที่ฝั่งเซิร์ฟเวอร์) · ช่วงวันเวลาเปิด-ปิด · จำนวนครั้งที่ทำได้ · รหัสเข้าสอบ · สุ่มข้อ · สุ่มตัวเลือก · แสดงทีละข้อ
- **บันทึกคำตอบอัตโนมัติ** ถ้าเน็ตหลุดหรือปิดเบราว์เซอร์ กลับมาทำต่อได้ และเมื่อหมดเวลาระบบส่งคำตอบให้เอง
- นับจำนวนครั้งที่ผู้เรียน **สลับแท็บ/ออกจากหน้าจอ** เพื่อช่วยป้องกันการโกงเบื้องต้น
- ผู้เรียน **รู้คะแนนทันที** หลังส่ง และได้ลิงก์ผลสอบเก็บไว้ดูภายหลัง (เช่น ตอนผู้สอนตรวจข้อเขียนเสร็จ)
- เลือกได้ว่าจะแสดงเฉลย: ไม่แสดง / แสดงทันที / แสดงหลังปิดสอบ

### การตรวจและผลสอบ
- ข้อปรนัยตรวจทันที ส่วนข้อเขียนให้ AI ตรวจได้ 3 แบบ: อัตโนมัติทันทีที่ส่ง / ตรวจทีละคน / ตรวจทั้งห้องในคลิกเดียว
- AI ให้ **คะแนนพร้อมคำแนะนำ** แล้วผู้สอน **กด +/− ปรับต่อจากคะแนน AI** กดยืนยัน หรือยกเลิกคะแนนที่ปรับเองได้
- **ตรวจใหม่ตามเฉลย** ได้ทั้งชุดเมื่อแก้เฉลยผิด (คะแนนที่ผู้สอนให้เองจะไม่ถูกเปลี่ยน)
- สถิติ: ค่าเฉลี่ย สูงสุด ต่ำสุด จำนวนที่ผ่านเกณฑ์ กราฟการกระจายคะแนน และ **วิเคราะห์รายข้อ** (ข้อไหนผู้เรียนตอบผิดเยอะ)
- ส่งออก **CSV** เปิดใน Excel ได้ ภาษาไทยไม่เพี้ยน

### AI ช่วยออกข้อสอบ
- พิมพ์หัวข้อ หรือวางเนื้อหาบทเรียนให้ AI ออกข้อสอบจากเนื้อหานั้นโดยตรง เลือกได้ทั้งประเภทคำถาม จำนวนข้อ ความยาก และภาษา (ไทย/อังกฤษ)
- ได้ผลแล้วดูตัวอย่างก่อน เลือกเฉพาะข้อที่ต้องการเพิ่ม และแก้ไขต่อได้ทุกข้อ

### คลังข้อสอบสาธารณะ
- ผู้สร้างเลือกเผยแพร่ชุดข้อสอบในคลังได้ พร้อมหมวดหมู่
- คนอื่นดูตัวอย่างได้ (เห็นเฉพาะโจทย์) และต้อง **กดคัดลอกไปไว้ในพื้นที่ตัวเองก่อน** จึงจะแก้ไข แชร์ต่อ หรือส่งให้ผู้เรียนทำได้
- ระบบบันทึกเครดิตว่า "คัดลอกจาก…" และนับจำนวนครั้งที่ถูกคัดลอก

### คอร์สเรียนแบบง่าย (ระบบไม่เก็บไฟล์)
- บทเรียนประกอบด้วยวิดีโอจากลิงก์ (YouTube, Vimeo, Google Drive, Facebook, .mp4) · โน้ต Markdown · ลิงก์เอกสารที่ฝากไว้ที่อื่น · แบบทดสอบท้ายบท
- **ติดตามผู้เรียน:** เปิดดูบทไหนแล้ว ดูกี่ครั้ง ดูวิดีโอ YouTube ไปกี่ % (วัดจากเวลาที่เล่นจริง) และผู้เรียนติ๊ก "เรียนจบแล้ว" เองได้
- ตารางความก้าวหน้า (ผู้เรียน × บทเรียน) แสดงคะแนนแบบทดสอบท้ายบทด้วย ส่งออก CSV ได้
- การรับผู้เรียนทำได้ 3 ทาง
  - ผู้สอนเพิ่มด้วยอีเมล วางได้หลายอีเมลพร้อมกัน ถ้าคนนั้นยังไม่มีบัญชี จะเข้าคอร์สอัตโนมัติเมื่อสมัคร
  - ผู้เรียนกดขอเข้าเรียน แล้วรอผู้สอนอนุมัติ
  - ตั้งคอร์สเป็น "ไม่ต้องอนุมัติ" ให้เข้าเรียนได้ทันที
- ตั้งบทเรียนเป็น "ดูตัวอย่างฟรี" ได้ และเลือกได้ว่าจะแสดงคอร์สในหน้ารวมคอร์สหรือไม่

### พื้นที่ โฆษณา และบริจาค
- ผู้ใช้แต่ละคนได้พื้นที่ **100MB** (นับรูปในข้อสอบและไฟล์คำตอบของผู้เรียนในข้อสอบของตน) เมื่อเต็มระบบจะแจ้งให้ติดต่อ **LINE OA @wasin**
- แอดมินเพิ่มโควตารายคนได้ที่หน้า "ผู้ดูแล"
- แบนเนอร์โฆษณาบน/ล่าง รองรับ Google AdSense และจะไม่แสดงในหน้าทำข้อสอบกับหน้าแก้ไข เพื่อไม่รบกวนผู้ใช้
- ปุ่ม **บริจาค (Buy Me a Coffee)** อยู่ที่แถบเมนูและท้ายเว็บ
- แอดมินจัดการผู้ใช้ได้: ระงับ รีเซ็ตรหัสผ่าน ตั้งเป็นแอดมิน ลบผู้ใช้ และดูสถานะ AI

## ⚙️ การตั้งค่า
ไม่ต้องใช้ Environment Variables เพราะทุกค่าตั้งได้ที่ **ผู้ดูแล → ตั้งค่าเว็บไซต์** และมีผลทันที ได้แก่
ชื่อเว็บ, LINE OA, พื้นที่ต่อผู้ใช้ (ค่าเริ่มต้น 100MB), ขนาดไฟล์สูงสุด, ลิงก์บริจาค, GitHub, โค้ดโฆษณา, ประกาศ, เปิด/ปิดรับสมัคร, เปิด/ปิด AI, ที่อยู่ AI Server, API Key และเวลารอ AI
(ผู้ใช้ขั้นสูงยังตั้ง env ได้ ดูตัวอย่างใน `.env.example` โดยจะใช้เป็นค่าเริ่มต้นครั้งแรกเท่านั้น)

## 🗂 โครงสร้างโค้ด
```
src/server.js        จุดเริ่มต้น (Express)
src/db.js            สร้างตาราง SQLite อัตโนมัติ
src/grading.js       ประเภทคำถาม + ตรวจอัตโนมัติ
src/ai.js            เชื่อม Ollama: สร้าง/แปลงข้อสอบ, ตรวจข้อเขียน, คิวงาน AI
src/models.js        จัดการโมเดล: ดาวน์โหลด/สลับ/ลบ/เช็กอัปเดต/รายการแนะนำ
ai-models.json       รายการโมเดลแนะนำ (แก้บน GitHub → ทุกเว็บเห็น)
src/routes/*.js      หน้าเว็บและ API (public, take, exams, courses, admin)
views/*.ejs          หน้าเว็บ (ภาษาไทย)
public/js/*.js       ตัวสร้างข้อสอบ / หน้าทำข้อสอบ (Alpine.js)
```
